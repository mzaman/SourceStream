🛠 CLI Setup Guide
AWS S3 (s3://bucket/prefix)
brew install awscli
aws configure # enter Access Key ID + Secret
Backblaze B2 (b2://bucket/prefix)
brew install b2-tools
b2 authorize-account # enter keyID + applicationKey
rclone — any cloud (rclone:remote:path)
brew install rclone
rclone config # interactive setup for any provider
